“Hybrid Test Automation Framework for Alphaware, built with a focus on high reliability and cross-platform scalability.”

**Tech Stack & Tools**
**Languages**: C# 12 (.NET 8/9).
**UI Automation**: Selenium WebDriver 4.x.
**Test Runners**: NUnit (for C#).
**Build Tools**: NuGet (C#)

 **Framework Architecture**
**Page Object Model (POM)**: To maintain clean separation between test logic and element locators.
**Data-Driven Framework**: Externalized test data using JSON or Excel for reusable test scenarios.

**Run Commands**: CLI command to trigger the suite:
C#: dotnet test
**CI/CD**: jenkins
